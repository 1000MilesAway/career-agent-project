# CLAUDE.md

**career-agent** — коммерческий SaaS для поиска работы на рынке РФ. Пайплайн взят
из open-source [career-ops](https://github.com/career-ops-hq/career-ops) (далее **CO**),
но продукт другой: не self-hosted CLI, а веб-сервис по подписке; не только IT, а любые
сферы; **без автооткликов** — отклик всегда отправляет человек.

Локальная копия CO: `/home/vpn/career-ops`. Это эталон поведения, а не библиотека:
сверяться с ней по коду и прогонять `node scan.mjs --dry-run`, когда решение спорное.
Улучшать пайплайн можно и нужно — но расхождение с CO осознанное и записанное
в `docs/decisions.md`, а не случайное.

## Инвариант пайплайна

**Дорогое — последним. Порядок ступеней ломать нельзя.**

```
сбор (API/превью, 0 ₽)
  → бесплатные фильтры (стоп-слова, специализация, грейд, вилка, 0 ₽)
    → история виденного (0 ₽)
      → triage: один дешёвый вызов на всю пачку (~0.01 ₽/вакансия)
        → полная оценка выживших (~0.17 ₽/вакансия)
          → артефакты отклика: резюме, письмо, интервью (~0.64 ₽)
```

Три правила, которые из этого следуют и не обсуждаются:

1. **Ни один платный вызов не делается до того, как отработали бесплатные ступени.**
   Нарушение = пользователь платит за мусор.
2. **Отсев никогда не молчит.** Любая выброшенная вакансия несёт причину одной
   строкой и остаётся видимой (приглушённой, под фильтром) — как `data/discard.log`
   в CO. Прятать вакансию без объяснения нельзя.
3. **Неполный ответ модели не достраивается.** Если пачечный вызов вернул меньше
   вердиктов, чем просили, пропуски идут в `missing` и показываются, а не
   доклеиваются как «skip». Тихо отсеять несуждённое — худший из возможных багов.

## Правило подтверждений

Агент **предлагает**, пользователь **принимает**. Ничего сгенерированного не пишется
в состояние без явного «да»: ни профиль поиска, ни правки стоп-списков, ни резюме.

Реализовано как сущность, а не как фраза в промпте: `probe/proposals.py` держит
`current` / `proposed` / `rationale`, отдаёт дифф и имеет статус. CLI печатает дифф
и спрашивает `[y/N]`; веб показывает таблицу изменений с двумя кнопками. Молчание =
отказ. `--yes` — только для неинтерактивных прогонов.

Поля, которых предложение не касается, не затираются.

## Чего не делать никогда

- **Автоотклик.** Ни в каком виде, ни по просьбе пользователя. Это позиционирование
  продукта и юридическая граница.
- **Скрейпинг hh.ru с сервера** и хранение чужих паролей от job-бордов.
- Читать Telegram через юзербот (Telethon) — личный аккаунт под баном ради открытых
  данных. Только публичное превью `t.me/s/`.
- Добавлять зависимости и продуктовый код, пока пользователь не попросил перейти
  от демо к реализации.
- Переоткрывать вопросы, закрытые в `docs/decisions.md`, без запроса пользователя.

## Ветки, CI и деплой

Настроено 2026-09-21. Подробности и причины — `docs/decisions.md`.

**`main` — рабочая версия. Всё, что в неё попало, едет на сервер.**

```
пуш в main  →  CI (тесты + ruff + миграции)  →  зелёный  →  деплой на 82.25.161.103
пуш в ветку →  CI только через PR            →  на сервер НЕ едет
```

Подтверждений не требуется: `main` не защищена, ревью никто не запрашивает.
PR нужен только если сам захотел работать через ветку — тогда «создать» и
«влить», и всё.

| Что | Где |
|---|---|
| Тесты, линтер, миграции | `.github/workflows/ci.yml` |
| Выкатка | `.github/workflows/deploy.yml` |
| Что делает выкатку на хосте | `~/deploy.sh` на сервере, **не в репозитории** |

Три правила, которые уже стоили сломанного пайплайна:

1. **Триггер деплоя — `push`, не `workflow_run`.** Последний читает своё
   определение из дефолтной ветки репозитория, и пока ею был не `main`, деплой
   молча не запускался вовсе — ни ошибки, ни прогона.
2. **Тесты не должны зависеть от того, чего нет в git.** `.env` и `data/` в
   `.gitignore`; набор, зелёный локально, падал в CI 27 ошибками. Секреты
   тестам задаёт `tests/conftest.py`, а не машина разработчика. Проверка:
   набор обязан проходить при пустом `DEEPSEEK_API_KEY`.
3. **Версию экшена искать в списке ТЕГОВ**, а не релизов
   (`git ls-remote --tags`): у `setup-uv` релизы дошли до 10.x, а плавающие
   мажорные теги кончаются на `v7`, и прогон упал на несуществующем `v10`.

Откат при неудаче автоматический: сборка упала или `/api/health` молчит 60 с —
`deploy.sh` возвращает предыдущую ревизию и поднимает её. Снимок состояния до
пайплайна — коммит `11ce666` в репозитории на сервере.

**Сервер тестовый**, обращаться к нему для проверок можно.

## Команды

Окружение — `uv`: системного `pip` на хосте нет (`ensurepip` отсутствует).

```bash
uv sync --group dev                  # зависимости из uv.lock
uv run pytest                        # тесты (324 шт., ключ API не нужен)
uv run ruff check .                  # линтер
uv run ruff check --fix .            # линтер с автоправкой
```

Демо-экран (порт — `PROBE_PORT`, авторестарт — `PROBE_RELOAD=1`):

```bash
uv run python -m probe.web           # http://127.0.0.1:8010
```

Продукт (`app/`) — нужен Postgres:

```bash
docker compose up -d                 # Postgres 16 на порту 5433
uv run alembic upgrade head          # накатить схему
uv run python -m app.cli user-add you@example.com   # завести учётку, пароль печатается один раз
uv run uvicorn app.main:app --reload # API на http://127.0.0.1:8000, /docs — схема
uv run python -m app.worker          # воркер очереди, отдельным процессом
```

`SECRET_KEY` обязателен: на значении по умолчанию приложение откажется
стартовать, потому что предсказуемый ключ позволяет подписать токен любому.

**Потолок расхода задаётся `SPEND_LIMIT_RUB`** (0 или меньше — без лимита).
Учёт в `users.spent_rub`, проверка — `spend.ensure_can_spend`, вызывается на
входе каждого платного шага; исчерпанный бюджет отвечает 402. Ключ DeepSeek
оплачивает владелец. В интерфейсе остаток пока не показывается — пользователь
узнаёт о лимите, только упёршись в него.

Бесплатные команды (модель не вызывается):

```bash
uv run python -m probe.run --help    # все подкоманды
uv run python -m probe.run tg        # вакансии из Telegram-каналов
uv run python -m probe.run cost      # сводка расходов по всем прогонам
uv run python -m probe.run calibrate # соблюдает ли скоринг свои правила
uv run python -m probe.run calibrate --source golden   # то же по эталонному набору
```

**Любой одноразовый прогон запускай с `PROBE_OUT`**, иначе он пишет в боевое
состояние: `PROBE_OUT=$(mktemp -d) uv run python -m probe.run ...`. Однажды
смоук-тест так стёр оплаченные оценки — см. `docs/decisions.md`.

Платные команды (обращаются к LLM):

```bash
# основной сценарий: фильтры до модели, как в CO
uv run python -m probe.run scan2 --resume data/resumes/cv.md --remote --limit 8

uv run python -m probe.run url   --resume data/resumes/cv.md --url <ссылка на Хабр>
uv run python -m probe.run one   --resume data/resumes/cv.md --vacancy data/vacancies/v1.txt
uv run python -m probe.run batch --resume data/resumes/cv.md --vacancies data/vacancies
```

Сверка с CO (бесплатно, без ключей):

```bash
cd /home/vpn/career-ops && node scan.mjs --dry-run
```

**После правки `.py` веб-сервер надо перезапустить** — процесс держит код в памяти,
и пользователь иначе смотрит на старый процесс. `index.html` перечитывается на каждый
запрос, его правки видны по F5.

## Ключевые решения (кратко; подробности и причины — в `docs/decisions.md`)

- **LLM:** DeepSeek через OpenAI-совместимый API. Имена моделей на боевом ключе —
  `deepseek-flash` (рабочая) и `deepseek-v4-pro` (сравнение). Обёртка тонкая,
  модель меняется конфигом.
- **Себестоимость (замер, off-peak):** разбор резюме 0.04–0.06 ₽ разово; оценка
  вакансии ~0.17 ₽ / 13 с; полный пакет ~0.81 ₽ / 54 с. Кэш префикса подтверждён.
- **Источники:** career.habr.com (публичный JSON API + страница вакансии) и
  Telegram-каналы через `t.me/s/`. Чаты недоступны в принципе — у групп нет превью
  (302), это не блокировка. hh.ru с сервера отдаёт 403; вопрос официального API открыт.
- **MVP-продукт:** веб-кабинет (React SPA) + FastAPI. Вход по email и паролю, учётки
  заводит админ CLI-командой; публичной регистрации, почты и оплаты в MVP нет.
- **Демо (текущая задача):** без авторизации вообще, состояние — файлы в `out/`.
- Telegram-бот и браузерное расширение отложены.

## Конвенции

- Python 3.12, ruff (`line-length = 100`, `select = ["E","F","I","UP","B"]`),
  pytest с `asyncio_mode = "auto"`.
- **Тексты для пользователя — по-русски, код и комментарии — по-английски.**
- Комментарий объясняет **почему**, а не что. Проверенная развилка («так нельзя,
  потому что ломается вот это») стоит комментария и записи в `decisions.md`.
- Внешние сервисы в тестах мокаются. **Живые вызовы LLM в тестах запрещены** —
  промпты проверяются снапшотами на записанных ответах (`tests/fixtures/`).
- Списки каналов, стоп-слов и запросов — **данные**, а не код: они устаревают тихо,
  и обновление не должно означать правку модуля.
- Секреты только в `.env`, в репозитории — `.env.example`.
- Фронтенд (когда появится): TypeScript, ESLint + Prettier, без классовых компонентов.
