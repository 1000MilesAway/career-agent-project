# План и риски

## Неделя 0 — проверка качества до кода — **ПРОЙДЕНА 2026-09-12**

Итог: промпты держат уровень, себестоимость ~0.17 ₽ за оценку и ~0.81 ₽ за полный пакет.
Стенд лежит в `probe/`, детали замера — в `docs/decisions.md`. Осталось прогнать
на 20–30 реальных вакансиях пользователя, чтобы подтвердить разброс баллов на живых данных.

Что было запланировано:
- Промпты `evaluate`, `tailor_resume`, `cover_letter` в виде скриптов.
- Прогон на 20–30 реальных вакансиях из разных сфер (IT, продажи, бухгалтерия, производство,
  маркетинг) на 3–4 разных резюме.
- Сравнить DeepSeek V4.1 Flash с одной сильной моделью глазами: честность скоринга,
  отсутствие выдумок в резюме, живость писем.
- Стоп-критерий: если оценки «всё на 4» или письма шаблонные — сначала чинить промпты.

## Неделя 1 — бэкенд
users, resumes, vacancies, evaluations, jobs, воркер, обёртка LLM, парсинг PDF/DOCX,
вход по email+паролю, CLI создания пользователя.
Результат: через REST можно завести пользователя и получить отчёт.

## Неделя 2 — веб-кабинет
React SPA: вход, согласие при первом входе, загрузка и правка профиля, форма вакансии
(текст/скриншот/ссылка), страница отчёта с прогрессом, действия письмо/резюме/интервью, трекер.
Результат: 10 тестеров из знакомых, учётки заведены вручную.

## Неделя 3 — упаковка
Лимиты (считаем и показываем, без оплаты), PDF-рендер резюме, лендинг (одна страница),
политика ПД, мониторинг, деплой. Результат: продуктом можно пользоваться и его не стыдно показать.

## Недели 4–6 — фидбек и деньги
Публичная регистрация и сброс пароля (появляется почта), подписка через ЮKassa,
промпты по сферам, follow-up в трекере, анализ отказов, статьи/SEO, решение по расширению.
Результат: можно брать деньги.

## Риски

| Риск | Действие |
|---|---|
| Качество Flash недостаточно для писем/резюме | обёртка позволяет переключить модель на конкретную задачу |
| hh.ru не даёт API | вход только текст/скриншот/ссылка на дружественные сайты; расширение как запасной канал |
| Оплата DeepSeek из РФ | нужна зарубежная карта или посредник; решить до недели 1 |
| 152-ФЗ, трансграничная передача | согласие + уведомление РКН + юрист на 2 часа до запуска |
| hh PRO за 699 ₽ с ИИ-письмами | не конкурировать письмами; продавать скоринг + тейлоринг + интервью |
| Пользователь ждёт автоотклик | явно говорить в онбординге и лендинге, чего сервис не делает |
| Веб требует больше UI-работы, чем бот | неделя 2 целиком на SPA; при отставании резать трекер, не отчёт |
| Ручное заведение учёток не масштабируется | это осознанно на время тестеров; регистрация — первое после MVP |
