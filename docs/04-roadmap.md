# План и риски

## Неделя 0 — проверка качества до кода — **ПРОЙДЕНА 2026-09-12**

Итог: промпты держат уровень, себестоимость ~0.17 ₽ за оценку и ~0.81 ₽ за полный пакет.
Замер делался на стенде `probe/` (удалён 2026-09-21), детали — в `docs/decisions.md`.

Что подтвердилось: модель ссылается на конкретный опыт, не выдумывает, ловит штампы
и сама замечает несовпадения между резюме и вакансией. Стоп-критерий «всё на 4»
не сработал — промпты можно нести в продукт.

Остаётся долгом: прогон на 20–30 реальных вакансиях из **разных сфер** (не только IT)
на 3–4 резюме. Пока проверено на IT-профиле и на резюме главбуха.

## Демо полного пайплайна — **ПРОЙДЕНО 2026-09-18, стенд удалён 2026-09-21**

Показывало сценарий целиком на одном экране, без входа и без БД, состояние —
файлы в `out/`. Свою задачу выполнило: пайплайн собран и проверен целиком.
Стенд `probe/` удалён, когда заработал автодеплой — см. `docs/decisions.md`.

### Готово

- Резюме: загрузка PDF/DOCX/TXT, разбор в профиль, память между перезапусками.
- Подбор по Хабр Карьере: сбор через публичный API, бесплатные фильтры, история виденного.
- Профиль поиска: модель предлагает, пользователь принимает диффом.
- Triage: один дешёвый вызов на пачку, три группы, причина у каждой, `missing` видим.
- Оценка одной вакансии с сохранением отчёта — повторный показ бесплатный.
- Учёт расходов по каждому вызову.

- Материалы к отклику: резюме под вакансию, письмо, подготовка к интервью — поверх
  готового отчёта, с выбором режима и его цены.
- Telegram как второй источник прямо на экране.
- Трекер: семь статусов, переходы пишутся в лог.
- Сводка расходов по найденному.

Сделано 2026-09-18, подробности и найденные ловушки — в `docs/decisions.md`.

## Дальше: продуктовый каркас

Заведён 2026-09-19. С 2026-09-21 — единственное, что развивается.

### Неделя 1 — бэкенд — **ПРОЙДЕНА 2026-09-19**

Сделано: ядро вынесено в `core/`; 7 таблиц
(`users`, `resumes`, `vacancies`, `evaluations`, `artifacts`, `applications`,
`jobs`) с миграцией Alembic; вход email+пароль (bcrypt, JWT); admin CLI
заведения учёток; 23 REST-эндпоинта; воркер задач на таблице `jobs`.
Учёт расходов по пользователю есть, лимитов нет — по решению пользователя.

292 теста (из них 47 против настоящего Postgres), ruff чист. Живых вызовов
LLM в тестах нет. Подробности и найденные ловушки — в `docs/decisions.md`.

Остаётся долгом по этой ступени:
- прогон полного платного сценария на живом ключе (сейчас проверены только
  бесплатные пути и пути с моком);
- парсинг вакансии по ссылке проверен только на сохранённом тексте.

### Неделя 2 — веб-кабинет — **SPA собрана 2026-09-21**

Кабинет переписан с одностраничного `app/static/index.html` на React SPA
(`frontend/`): Vite, TypeScript, SWR, react-router; отдаётся своим контейнером
с nginx, который проксирует `/api`. Подробности и две пойманные ловушки
nginx — в `docs/decisions.md`.

Сделано: вход, три страницы (резюме / поиск / избранное), подбор с бесплатным
отсевом, triage, оценка, материалы к отклику поштучно, трекер, расходы
с остатком бюджета, экран подтверждения профиля поиска (раньше ручки API были
недостижимы из интерфейса), отчёт в боковой панели, тосты.

13 тестов интерфейса, отдельное задание в CI (линтер, типы, тесты, сборка).

Остаётся по этой ступени:
- **посмотреть экран глазами в браузере** — Chromium в песочнице агента не
  запускается, проверен только контракт с API и разметка тестами;
- согласие при первом входе (`consent_at` в API есть, экрана нет);
- форма вакансии по ссылке или текстом (сейчас только подбор источниками);
- прогресс длинной задачи через `/api/jobs` (сейчас кнопка ждёт ответа);
- 10 тестеров из знакомых.

## Риски

| Риск | Действие |
|---|---|
| Качество Flash недостаточно для писем/резюме | обёртка позволяет переключить модель на конкретную задачу |
| hh.ru не даёт API | вход только текст/скриншот/ссылка на дружественные сайты; расширение как запасной канал |
| Оплата DeepSeek из РФ | нужна зарубежная карта или посредник; решить до недели 1 |
| 152-ФЗ, трансграничная передача | согласие + уведомление РКН + юрист на 2 часа до запуска |
| hh PRO за 699 ₽ с ИИ-письмами | не конкурировать письмами; продавать скоринг + тейлоринг + интервью |
| Пользователь ждёт автоотклик | явно говорить в онбординге и лендинге, чего сервис не делает |
| Веб требует больше UI-работы, чем бот | неделя 2 целиком на SPA; при отставании резать трекер, не отчёт |
| Ручное заведение учёток не масштабируется | это осознанно на время тестеров; регистрация — первое после MVP |
| Демо перерастает в продукт незаметно | снято: демо удалено 2026-09-21, продукт единственный |
| Проверено только на IT-профиле | долг недели 0: прогон на резюме из других сфер до недели 1 |
