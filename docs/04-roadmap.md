# План и риски

## Итог MVP — 2026-10-01

**MVP собран и стоит на `career-helper.site`** (ревизия `b03674b`). Годится для
тестеров, но **не для открытой регистрации**, хотя регистрация по почте и через
Telegram уже включена: не закрыты блокеры ниже.

### Что вошло

- Пайплайн целиком: разбор резюме → бесплатные фильтры → triage → оценка →
  резюме под вакансию, письмо, подготовка к интервью. Порядок ступеней
  закреплён, отсев с причиной, `missing` видим.
- Источники: Habr Карьера, Telegram (`t.me/s/`), geekjob, сайты работодателей
  и ATS; дедуп между источниками, проверка живости, фильтр по IT-аккредитации.
  Скан — фоновая задача.
- Резюме: PDF / DOC / DOCX / RTF / текст, ручная правка разобранного, версии
  с откатом, выгрузка в PDF / DOCX / MD с конструктором стиля.
- Чат-помощник: предлагает правки профиля, пользователь принимает диффом.
- Трекер-воронка с переносом мышью, избранное, скрытие.
- Вход: email+пароль, регистрация с подтверждением почты (Resend), Telegram
  (OIDC). Онбординг-тур.
- Квоты по тарифам (день/неделя), пользователю — только доли, не деньги.
- Инфраструктура: CI → автодеплой с автооткатом, HTTPS через Caddy, `revision`
  в `/api/health`.

**Разошлось со спекой** (`02-product-spec.md` не обновлена): сканирование
источников и самостоятельная регистрация числились «не в MVP», а стали его
ядром; оценка вакансии, присланной пользователем, наоборот, не сделана.

### Готово

- Резюме: загрузка PDF/DOCX/TXT, разбор в профиль, память между перезапусками.

- Материалы к отклику: резюме под вакансию, письмо, подготовка к интервью — поверх

- Трекер: семь статусов, переходы пишутся в лог.
- Сводка расходов по найденному.

      галочкой). Архетипы с `tier` уже есть; не хватает переключения
      активных направлений и выдачи по каждому. Крупно: `search_profile`
      сейчас один на пользователя. Сначала спросить тестеров, ищут ли они
      больше чем по одному направлению.
- [ ] **Метка «ранний отклик»** (Jobright «Be an early applicant», фильтр
      «за 24 часа»). Вакансия моложе суток — метка на строке, фильтр
      «новое за сутки». 0 ₽, дата публикации в пуле есть.
- [ ] **Звёзды интереса в избранном** (Teal excitement 1–5). Сортировка
      избранного по собственному интересу, а не только по баллу модели.
      Мелочь; брать вместе с заметкой.
- [ ] **Разбор своего резюме на hh.ru** (аналог LinkedIn Optimizer у
      Careerflow): заголовок, навыки, ключевые слова, по которым рекрутер
      находит резюме в поиске hh. Отложено: резюме на hh читает только
      провайдер, и сначала проверить спрос.

Дизайн, который стоит взять (под пункты выше, когда до них дойдёт):

- **Jobright, карточка вакансии:** процент в цвете метки, под ним три оси
  числами; при раскрытии — правая колонка «почему подходит / чего нет»
  с конкретным пробелом, а не общим советом. У нас вердикт уже ведёт
  строку — добавить оси, не меняя облик.
- **Teal, Matching Mode:** требования вакансии подсвечены в её тексте, и
  у каждого — где в резюме оно уже есть. Для нашего отчёта: клик по
  требованию — подсветка цитаты `jd_signal` в тексте вакансии.
- **Careerflow, оптимизация резюме:** две колонки «было / стало» по
  каждому пункту с кнопками «принять / отклонить» и балл, растущий по
  мере принятия.
- **Huntr, метрики:** воронка с процентами переходов между стадиями,
  столбики откликов по неделям, лента событий по каждой вакансии
  (`status_log`).
- **JobPilot, треки:** направления карточками с галочкой «активно» и
  своим счётчиком новых вакансий.
