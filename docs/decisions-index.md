# Индекс решений

Короткая выжимка `docs/decisions.md`: одна строка на запись журнала, сгруппировано
по темам. **Читать этот файл, а не журнал целиком** (журнал — больше 3000 строк).
Полная запись с причинами и проверенными развилками находится грепом по заголовку:

```bash
grep -n "Общий пул вакансий" docs/decisions.md   # → номер строки, дальше Read с offset
```

Строка: что действует сейчас → дата и точный заголовок записи. **[отменено]** и
**[история]** — запись не описывает текущее поведение; читать её только ради урока.

Новое решение: запись в конец `decisions.md` + строка сюда в нужную тему.
`tests/test_decisions_index.py` падает, если у записи журнала нет строки здесь.
