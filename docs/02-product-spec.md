# Продуктовая спецификация MVP

> Сверено с `docs/decisions-index.md` 2026-10-07. При расхождении прав индекс решений.

## Цель MVP

Проверить, что люди платят за **оценку и подготовку**, а не за автоотклик.
Один сценарий, доведённый до конца: пользователь загружает резюме → присылает вакансию →
получает оценку и материалы → ведёт статус в трекере.

## Целевая аудитория

Соискатели любой сферы (не только IT), ищущие работу через hh.ru / Авито / SuperJob /
Telegram-каналы. Первичный сегмент для запуска — специалисты с опытом 2+ лет, у которых
есть из чего собирать STAR-истории и кому есть что тейлорить.

## Каналы входа

- **Веб-кабинет** — единственный интерфейс MVP. Адаптивная вёрстка, работает с телефона.
- Telegram-бот — не в MVP, возможный второй канал позже (см. `decisions.md`).
- Браузерное расширение — отложено (см. `decisions.md`).

## Пользовательские сценарии

### 1. Онбординг
1. Вход: email + пароль или Telegram. Учётку по email создаёт администратор
   (CLI-команда) или сам пользователь — регистрацией с подтверждением почты по
   ссылке из письма (с 2026-09-30, см. `decisions.md`). Забытый пароль
   сбрасывается по ссылке из письма (с 2026-10-04).
   Согласие на обработку ПД (обязательно, см. риски) — экран при первом входе,
   там же краткое объяснение, что сервис делает и чего **не** делает
   (не откликается за вас).
2. Загрузка резюме: PDF / DOC / DOCX / RTF / вставка текстом. С hh.ru пользователь скачивает PDF сам.
3. Сервис парсит резюме в структурированный профиль и показывает его в виде формы
   («вот как я вас понял») — пользователь проверяет и правит поля прямо на странице.
4. Опционально: сфера, желаемая должность, вилка, формат (офис/удалёнка), город.

### 2. Оценка вакансии
Вход (любой из):
- ссылка — кнопка «Добавить» в «Избранном»: Хабр Карьера, geekjob, hh.ru (через
  провайдер) или сайт компании из нашего поиска (ищется в пуле, без запроса). Другие
  сайты, Telegram и вставленный текст не принимаются (решение 2026-10-08);
- вакансия из подбора по всем источникам (см. «Источники» в индексе решений).

Выход — **отчёт** (см. схему в `03-architecture.md`):
- итоговый балл 1–5 и вердикт (откликаться / с оговорками / не тратить время);
- соответствие по требованиям: что совпадает, чего не хватает, что критично;
- красные флаги (размытые обязанности, «многозадачность», нет вилки, признаки фейка);
- зарплатная оценка относительно рынка (по знанию модели + вилка из вакансии);
- 3–5 вопросов работодателю;
- действия по вакансии (см. ниже).

### 3. Действия по вакансии (со страницы отчёта)
- **Резюме под вакансию** — переупаковка опыта под требования, одноколоночный PDF/DOCX
  (раздела «Ключевые слова» нет с 2026-10-06).
- **Сопроводительное** — 3 варианта угла подачи на выбор, затем текст.
- **Подготовка к интервью** — вероятные вопросы + STAR-истории, собранные из опыта пользователя,
  + что подтянуть до интервью.
- **В трекер** — сохранить со статусом «оценено».

### 4. Трекер
Статусы: оценено → откликнулся → тест/скрининг → интервью → оффер / отказ / тишина.
Отдельная страница-таблица со сводкой по активным. Смена статуса прямо в строке.
Через 7 дней после «откликнулся» без обновления — вакансия подсвечивается в таблице
как требующая внимания (писем-напоминаний нет).
После 5+ отказов — анализ паттерна (что общего у вакансий, где отказали).

### 5. Оплата и лимиты

Действует с 2026-10-01 (подробно — decisions «Экономика…» и «Бесплатный лимит удвоен»):
- лимит — дневное и недельное окно в себестоимости вызовов; пользователь видит только проценты;
- бесплатный тариф и подписка 349 ₽/мес; подписку пока выдаёт админ, приёма оплаты нет;
- провайдер оплаты — ЮKassa, когда до неё дойдёт.

## Не входит в MVP

- Автоотклик в любом виде.
- Интеграция с аккаунтом hh.ru (OAuth, парсинг резюме из аккаунта).
- Telegram-бот, браузерное расширение.
- Приём оплаты.
- Поиск контактов рекрутеров, LinkedIn.
- Многоязычность (только русский).

## Метрики успеха MVP

- Активация: доля дошедших от первого входа до первого отчёта.
- Retention: доля вернувшихся со второй вакансией в течение 7 дней.
- Конверсия в оплату после исчерпания бесплатных оценок (меряем, когда появится приём оплаты).
- Качественная: пользователи говорят «оценка была честной/полезной» (опрос в кабинете после 5-й оценки).
