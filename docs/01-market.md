# Рынок и конкуренты

Дата исследования: 2026-09-12.

## Референс: career-ops

Open-source «Agent Skill» для AI-CLI (Claude Code, Codex, OpenCode и др.), MIT, ~71k звёзд.
Что делает:
- сканирует Greenhouse/Lever/Ashby/Wellfound и карьерные страницы 100+ компаний;
- оценивает вакансию против CV по структурированному «A–H отчёту» с итоговым баллом 1–5
  (summary роли, соответствие CV с весами требований, вилка, персонализация, STAR+R подготовка,
  проверка на «фейковость»);
- генерирует ATS-PDF резюме под вакансию, сопроводительное, черновик письма;
- трекер откликов, анализ паттернов отказов;
- **никогда не отправляет отклик сам** — human-in-the-loop, рекомендует не откликаться ниже 4.0/5.

## Hirify (hirify.me) — агрегатор, а не помощник

Разобран 2026-09-23. Джоб-борд для IT и Digital с AI-функциями в подписке
(Plus: 399 ₽/мес, 990 ₽/3 мес, 1 990 ₽/год, разовым платежом). Автооткликов нет;
глубокой оценки, резюме под вакансию и подготовки к интервью тоже нет — есть
«прожарка» резюме, мэтч и письмо в двух длинах. Фаундер один, без инвестиций.

Сила — ширина сбора. По их же открытому API (`api.hirify.me/api/vacancies`,
фильтр по источнику):

| Класс | Активных | Что это |
|---|---|---|
| Global | 230 766 | краулер по сайтам ~6 200 зарубежных компаний и ATS |
| hh | 11 113 | вакансии hh.ru, по умолчанию скрыты |
| Telegram | 9 899 | «960+ каналов» — включая чаты, то есть юзербот |
| Hirify RU | 3 540 | сайты российских tech-компаний |
| Ru-global | 3 309 | ~600 компаний «с восточноевропейскими корнями» |
| Рекрутеры | 522 | размещённые напрямую |

То есть по рынку РФ у них ~28 тыс., и три четверти — Telegram и hh. Что у них
стоило перенять (сбор с сайтов компаний, проверка живости, дедуп) — сделано,
см. `docs/decisions.md`, 2026-09-23. Чего не копируем: чаты Telegram через
юзербот и hh — оба запрещены в CLAUDE.md.

## Ситуация с hh.ru

hh.ru — фактический монополист, и он выдавливает соискательские сервисы:
- **15.12.2025** — закрыт API резюме для сторонних соискательских сервисов;
- **апрель 2026** — публичный `GET /vacancies` отдаёт 403 без авторизации;
- ключи API выдают только верифицированным работодателям после модерации приложения;
- автоотклики нарушают правила, аккаунт могут заблокировать без восстановления;
- есть капча, IP-баны; лимиты ~200 откликов/день, ~3 000/мес;
- умерли: Hirecraft, HeadHunter Lightning, HH Go, JobTurbo (частично);
- выжившие живут в серой зоне: эмуляция браузера, серверные сессии, «человеческий» темп;
- hh запустил свой ИИ (ИИ-сопроводительные в hh PRO, ИИ-ассистент для рекрутеров с ноября 2025).

Вывод: строить бизнес на интеграции с аккаунтом hh — строить на платформе, которая
активно борется с такими сервисами и одновременно продаёт свою подписку за 699 ₽.

## Позиционирование

Одно принципиальное отличие: конкуренты продают **объём откликов**, мы продаём
**качество решения, куда откликаться и с чем**.

1. Они автоматизируют отправку — мы автоматизируем оценку (честный скоринг 1–5, чего не хватает,
   рекомендация не откликаться ниже порога).
2. У них одно резюме на все вакансии — у нас резюме под каждую (ATS-ключи, переупаковка опыта).
3. У них ничего нет после отклика — у нас подготовка к интервью (STAR из опыта пользователя),
   анализ отказов, трекер воронки.
4. Они в серой зоне hh — мы не трогаем аккаунт hh, банить не за что.
5. Они про IT и hh — мы про любую сферу и любой источник вакансии.

Фраза для лендинга: «конкуренты — спам-бот для hh.ru; мы — карьерный консультант за 50 000 ₽,
упакованный в подписку за 2 000».
