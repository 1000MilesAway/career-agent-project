# Кабинет career-agent

React SPA. Оценка вакансий по резюме; отклик отправляет человек.

## Разработка

Нужен Node 22 и запущенный API на `127.0.0.1:8000`.

```bash
npm ci
npm run dev          # http://127.0.0.1:5173
```

`/api` проксируется на API — браузер остаётся на одном origin, как и
в продакшене. Другой адрес: `VITE_API_TARGET=http://host:port npm run dev`.

```bash
npm test             # тесты, сети не требуют
npm run typecheck    # все три проекта TS, включая тесты
npm run lint         # oxlint
npm run build        # сборка в dist/
```

## Как это устроено

| Путь | Что |
|---|---|
| `src/api/types.ts` | контракт: формы, которые отдаёт `app/api/*.py` |
| `src/api/client.ts` | единственное место, знающее про токен; 401 разлогинивает |
| `src/api/hooks.ts` | SWR по ключу `/api/state` и мутации |
| `src/pages/` | три страницы: резюме → поиск → избранное |
| `src/components/` | строка вакансии, панель отчёта, дифф профиля, тосты |

**Данные — один payload.** `/api/state` отвечает на вопрос «что показать
сейчас», и сервер построен так намеренно. SWR отдаёт всем страницам одну
кэшированную копию: три страницы — один запрос, а мутация ревалидирует его
одним вызовом.

**Маршрутизация по хешу.** Кабинет отдаётся статикой, и путь вида `/search`
при перезагрузке упёрся бы в 404 везде, где сервер не переписывает неизвестные
пути на `index.html`. Хеш работает одинаково и в Vite, и в nginx.

## Правила продукта, которые держит интерфейс

Это не стилистика — это то, ради чего экран существует. Каждое закреплено
тестом, причины — в `docs/decisions.md`.

1. **Отсев никогда не молчит.** Выброшенная вакансия остаётся на экране
   приглушённой и несёт причину одной строкой. Спрятать её нельзя.
2. **Неполный ответ модели не достраивается.** `missing` и `unknown` из
   triage показываются как есть; несуждённая вакансия — не отсеянная.
3. **Агент предлагает, пользователь принимает.** Профиль поиска меняется
   только через дифф с кнопкой. Поля, которых предложение не касается,
   не затираются.
4. **Кнопка называет свою цену** до нажатия, а купленный документ
   открывается бесплатно и помечен галочкой.
5. **«Очистить» не трогает избранное** — там лежит оплаченное.
